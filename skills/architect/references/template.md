# Шаблон документа декомпозиции

Заполняй по фазам. Пустой раздел — это не «пока не дошли», это найденный пробел: либо заполни,
либо напиши, почему он неприменим.

Документ показывается на воротах (фаза 5) целиком.

---

## Задача

Одним абзацем: что строим и зачем. Без технических деталей.

**Ветка:** greenfield / надстройка над существующим / модификация работающего

**Пользователь и сценарий:** кто и что делает. Конкретно, не «пользователи хотят».

**Критерий готовности:** по чему видно, что работает. Наблюдаемо снаружи.

**Ограничения:** срок, стек, хостинг, бюджет, что нельзя ломать.

**Не делаем в этой итерации:**
- …
- …

*(Этот список защищает от расползания сильнее, чем всё остальное вместе взятое.)*

*(Каждая строка последней таблицы должна быть обоснована. «Не искал» — не обоснование.)*

## Части

Для каждой:

### <название>

- **Вход:** …
- **Выход:** …
- **Проверяется в одиночку:** да / нет — как именно.
- **При отказе:** что перестаёт работать.

## Пути и выбор

| Путь | Стоимость сейчас | Стоимость владения | Что теряем | Замок |
|---|---|---|---|---|
| A | | | | |
| B | | | | |

**Вариант «80% за 20%»:** что это и чего лишаемся.

**Рекомендация:** какой путь и почему. Одна, не «на ваш выбор».

**Сознательный долг:** где делаем грубо и при каком условии возвращаемся.

допущение проверяется первым.
